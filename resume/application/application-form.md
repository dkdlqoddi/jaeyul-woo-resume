## 2. AI 활용 경험 (필수, 최소 50자 · 최대 2000자)

주최 측(SK하이닉스 AI 해커톤 2026)이 밝힌 기준은 세 가지입니다: ZERO-BASE(배경 무관, 논리적 AI 활용 능력과 문제 해결의 집요함), REAL BUSINESS(반도체 현장의 실제 과제), SHOW & PROVE(작동하는 결과물). 아래 답변은 첫 문장에서 현업(사내 LLM API 기반 EDA 툴 자동화·파라미터 수집·로그 파싱)을 밝히고, 결과물을 번호로 나눠 수치와 함께 제시합니다.

현재 1788자 (공백·줄바꿈 포함) / 공백 제외 1439자. 양식 카운터가 공백을 포함해도 2000자 이내입니다.

```
저는 파운드리 설계 지원 현장에서 사내 LLM API로 EDA 툴 실행을 자동화하고, 설계 파라미터 값을 수집하고, 툴 로그를 파싱해 저장하는 반도체 설계 자동화 업무를 하고 있습니다. 모르는 도메인을 만나면 먼저 AI로 '도서관'과 '지식 지도(Knowledge Map)'를 만들고 그 위에서 프로그램을 짓는 것이 제 방식입니다. Claude Code(계획·리뷰), Codex CLI(교차 검증), Antigravity(대량 병렬 실행)를 역할을 나눠 함께 쓰며, 2026년 4월부터 9월까지 로컬 사용 기록 기준 약 114억 토큰의 컨텍스트를 처리해 신규 저장소 46개, 고유 커밋 1,800건 이상을 만들었습니다. 결과물 중심으로 정리하면 다음과 같습니다.

1) 도서관과 지식 지도: 반도체 설계 사인오프 흐름, EDA 툴 로그와 SOP처럼 제가 몰랐던 도메인 자료를 raw 원문으로 보존하고, Claude Code가 출처·개체·개념·주제 위키 마크다운을 유지하도록 만든 LLM 위키를 구축했습니다(커밋 120건). Next.js 앱이 GraphRAG와 BM25 하이브리드 검색을 제공하고, 헤드리스 인제스트에는 권한 deny 목록을 걸어 문서 속 프롬프트 인젝션이 소스를 건드리지 못하게 했습니다. 코드베이스의 지식 지도는 규칙·지도·명세 3계층 문서와 한 줄짜리 결정 기록으로 관리해, 10명이 동시에 Claude Code로 개발할 저장소의 ADR 66건과 요구사항 137건을 이관했습니다.

2) 설계 현장의 프로그램: 툴 Run 결과와 체크리스트를 집계해 사인오프 진행을 보여 주는 대시보드 GAIA 2.0(Next.js 16, Prisma·PostgreSQL 모델 23개, API 41개, 모듈 19개, 커밋 850건 이상)을 마일스톤 Score·Gantt·Run 파생 트리·floorplan 편집기·리포트 이메일 발송까지 에이전트 주도로 구현했고, Playwright e2e와 셀프호스팅 러너 CI로 검증했습니다. 넷리스트 파싱·DB 적재 파이프라인과 LangGraph 로그 분석 플로우도 같은 방식으로 만들었습니다.

3) 에이전트가 사내 서버와 LLM을 안전하게 쓰게 하는 인프라: 디렉터리별 read/write/command 정책으로 파일·명령·DB 질의·내부 API를 노출하는 MCP 서버(툴 17개), 사내 LLM 게이트웨이 프록시와 MCP 릴레이를 담은 FastAPI 서버, OpenCode에 EDA 벤더 MCP 3종을 연결한 지식 자동화 하네스, OpenCode 호환 Agent Skill 공유 허브(릴리스 불변성·감사 로그)를 구축했습니다.

4) 개발 방법 자체를 도구로: 코드를 쓰기 전에 모르는 것을 질문으로 바꾸는 blindspot-pass 스킬과 codebase-scanner 에이전트, 결정 기록으로 이루어진 공개 하네스 dev-env-blindspot을 만들어 15개 이상 프로젝트에 배포했습니다. Claude Code가 Opus로 계획·리뷰하고 Antigravity가 Gemini Flash로 병렬 실행하는 2-하네스 스웜, 구독 중인 CLI를 실행 엔진으로 재활용하는 오케스트레이터 cheap-agent, Antigravity CLI를 OpenAI 호환 API로 바꾸는 custom-llm-api를 공개했고, 같은 프롬프트로 Opus와 Fable을 비교한 벤치마크도 정리했습니다.

5) 확산: 설계 AX 전환, 안전한 AI 설계 자동화 아키텍처, DX vs AX, Agent Skills 철학, EDA MCP 하네스, AI 도구 입문, NotebookLM 등 팀 세미나 7편을 발표했고 자료는 dkdlqoddi.github.io에 공개했습니다.
```
